FluxPerf · 145 UI Design Concepts

Twenty visual themes covering ten screens for an enterprise API performance-testing platform on k6 OSS — scenarios & CSV data mapping, load profiles, K8s/Linux execution, SSE live monitoring, LoadRunner-style results analysis & SLA reporting, A/B run comparison, transaction flow composer, runner fleet management, and RBAC with full audit trail — plus the Crimson Ink family and full 10-screen deep-dives. Every file is fully self-contained.

105 left-menu designs (85 sidebar + 20 icon rail) 35 top-menu designs 82 dark · 63 light +5 Ink family · +40 deep-dive suites

Editor's Top 5 one click to the flagship screen

#1
Deep Ocean designs 66–70
Fintech navy + sky blue. Stunning analysis screens, dark UI made for long monitoring sessions.
 #2
Porcelain Blue designs 91–95
Data-dense trading-desk light UI. Best tables for audit, SLA reports and run history.
 #3
Neon Pulse designs 01–05
Flagship modern SaaS look. The live monitor with glowing metrics is the best single screen here.
 #4
Carbon Fiber designs 71–75
Industrial graphite with mono heads. Reads like serious infra tooling; great fleet screens.
 #5
Enterprise Blue designs 06–10
The safe corporate classic. Zero-risk choice; cleanest forms for scenario building.
